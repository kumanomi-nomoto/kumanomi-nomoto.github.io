## このブログについて

このブログでは、サイバーセキュリティに関する観測・分析・検証の記録をまとめています。

主に以下のテーマを扱います。

- Honeypot 
- IoT malware / botnet
- Vulnerability / Exploit observation
- AI / Agent security
- Network security
- Malware analysis

実際に観測した通信やログをもとに、
「何が起きているのか」「どのような攻撃意図が考えられるのか」を整理していきます。

## 目的

単なる攻撃情報の紹介ではなく、
観測データから攻撃活動やインフラ、脆弱性との関係を考えることを目的としています。

このブログは、自分自身の調査・研究・学習記録も兼ねています。
